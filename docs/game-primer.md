# Game Primer

Arrow Cloud supports In The Groove (ITG), a rhythm game played on a dance pad with 4 arrows (left, down, up, right). Players step on arrows in time with the music.

This doc gives engineers (and their agents) the game context needed to judge whether a change is correct. It is maintained by Wafles; if something here is missing or unclear, ask rather than guess.

## Rules of engagement
- Anything that changes scoring, charts, leaderboards, rankings, or what players see about their performance is `domain: game` and needs Wafles' sign-off.
- UX, design, performance, tests, infra and web best practices are `domain: general` and open to your judgment.
